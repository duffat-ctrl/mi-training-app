# MIエクササイズ・ラボ（Gemini版）

動機づけ面接（MI）の対話スキルを、AIを相手役にしたロールプレイで練習できるアプリです。
「開かれた質問」「是認」「聞き返し」「サマライズ」などOARSの基礎スキルから、「チェンジトーク」「維持トークへの対応」「不協和（バッティング練習）」といった応用編まで、全12種類のエクササイズを収録しています。

このアプリはGoogleのGemini APIを使って動作します。**利用にはご自身のGoogle AI StudioのAPIキーが必要です**（無料で取得できます）。

---

## 使い方

### 1. APIキーを取得する

1. [Google AI Studio](https://aistudio.google.com/apikey) にアクセスします
2. お使いのGoogleアカウントでログインします
3. 「Create API key」（APIキーを作成）をクリックします
4. 発行された文字列（`AIza`から始まります）をコピーしておきます

> 無料枠の範囲内であれば、費用はかかりません。無料枠の詳細や最新の料金体系は [Gemini API Pricing](https://ai.google.dev/pricing) でご確認ください。

> **キーが`AIza`ではなく`AQ.`から始まる場合**：現在Google AI Studioで新規発行されるキーは`AQ.`形式が標準になっています。間違いではないので、そのまま使って問題ありません。アプリ側は`AQ.`形式のキーにも対応しています。

### 2. アプリを開く

1. このリポジトリから `mi_exercise_lab_gemini.html` をダウンロードします
2. ダウンロードしたファイルをダブルクリックして、ブラウザ（Chrome、Edge、Safariなど）で開きます
   - インターネット接続があれば、そのまま動作します
   - サーバーへのアップロードやインストール作業は不要です

### 3. APIキーを設定する

1. アプリ画面の一番上にある「**APIキー設定 ▼**」をクリックして設定パネルを開きます
2. 「Google AI StudioのAPIキー」欄に、手順1でコピーしたキーを貼り付けます
3. 使用するモデルを選びます（迷ったら初期設定の「Gemini 3.6 Flash」のままで問題ありません）
4. 「保存」を押します
5. 上部の表示が「● APIキー設定済み」になれば準備完了です

### 4. エクササイズを選んで練習する

1. トップ画面でカテゴリー（例：「聞き返し」「チェンジトーク」）を選びます
2. カテゴリー内に複数の練習がある場合は、一覧から1つ選びます
3. エクササイズ詳細画面の「**あなたがすること**」を読んでから、「このエクササイズを始める」を押します
4. AIが最初の一手（閉じた質問の提示、患者役としての発言など）を自動で出します
5. あとはチャット形式でやり取りするだけです
   - `Enter` で送信、`Shift + Enter` で改行
6. 別の練習に切り替えたいときは「← 終了してメニューへ戻る」を押します

## APIキーの取り扱いについて

- 入力したAPIキーは、**ブラウザのメモリ上にのみ**保持されます
- ページを再読み込み（リロード）すると、入力したキーは消えます。毎回開き直すたびに再入力が必要です
- APIキーはご自身のGoogleアカウントに紐づく個人情報です。**他人と共有したり、SNS等に貼り付けたりしないでください**
- このファイル自体（HTMLファイル）にAPIキーは含まれていません。誰かに配布しても、あなたのキーが漏れることはありません

## うまく動かないとき

| 症状 | 確認すること |
|---|---|
| 「APIキーが未設定です」と表示される | 上部の「APIキー設定」からキーを入力・保存したか確認してください |
| 「APIリクエストに失敗しました（status 401）」と表示される | APIキーの入力ミス（余分な空白など）でなければ、Googleの新しいキー形式（`AQ.`）まわりの一時的な不具合の可能性があります。時間をおいて再度お試しください |
| 応答が返ってこない・ブロックされる | Gemini側の安全フィルタに引っかかっている可能性があります。別のモデルを試すか、少し表現を変えて送信してみてください |
| 画面が真っ白になる | ブラウザを最新版に更新してから、もう一度ファイルを開き直してください |
